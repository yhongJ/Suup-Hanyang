# 수업하냥

한양대학교 서울캠퍼스 빈 강의실 찾기 서비스

> 학생이 만든 비공식 서비스로, 한양대학교와 관련이 없습니다.

## 기능

- **빈 강의실 찾기**: 지금 비어 있는 강의실과 다음 수업까지 남은 시간
- **강의실 시간표**: 건물·강의실별 요일 시간표
- **수업 상태 체크**: 학교 이메일 인증 후 "수업 끝났어요 / 휴강이에요 / 아직 수업 중이에요" 제보. 여러 명이 체크하면 빈 강의실 목록에 반영

## 수업 상태 판정

| 상태 | 조건 |
|---|---|
| 끝남 | 끝남 체크 2명 이상, 수업 중 체크보다 많음, 마지막 체크 10분 이내 |
| 휴강 | 휴강 체크 2명 이상, 수업 중 체크보다 많음 |

- 끝남은 종료 60분 전부터, 휴강·수업 중은 수업 시작부터 체크 가능
- 같은 강의실·시간대에는 1인 1회

## 개인정보

- 수집 항목: 학교 이메일 주소 (인증용)
- 인증 코드와 로그인 토큰은 암호화(해시)해서 저장
- 체크 기록은 다른 사용자에게 공개하지 않음
- 시간표 데이터는 이 저장소에 포함하지 않음

## 기술 스택

- Backend: Java 21, Spring Boot 3, Gradle, MySQL, Flyway
- Frontend: HTML, CSS, JavaScript
- Infra: Docker, Nginx, Let's Encrypt

## 로컬 실행

```bash
docker compose up -d                 # MySQL
cd backend && ./gradlew bootRun      # 서버 (localhost:8080)
```

`frontend/index.html`을 로컬 서버(VS Code Live Server 등)로 열면 됩니다. 백엔드 없이 화면만 보려면 `frontend/js/config.js`에서 `USE_MOCK: true`로 설정하세요.
